# Security policy

Report vulnerabilities privately through GitHub's "Report a vulnerability" button on the Security tab. Do not open a public issue for a security problem.

Please include the affected version or commit, what an attacker could do, and steps to reproduce. Do not include real logs, addresses, or notification topics.

netguard is a read-only monitor, not a security audit or a replacement for firewalls and endpoint protection. See the Limitations section of the README.
